# Teste de aptidões

## Introdução
Para avaliar um pouco do seu conhecimento técnico e a sua forma de resolver problemas, propomos um breve desafio.

O desafio consite em criar um banner em 3 formatos diferentes e posteriormente transformá-lo em um vídeo de 15 segundos.

Com isso, o nosso intuito é analisar as suas habilidades para criar e desdobrar uma mesma peça em diferentes formatos.


##  Vamos ao desafio:

O cliente John&Cia solicitou banners para divulgação de um dos seus principais produtos: **As Trufas Importadas Hazel.**

### BRIEFING

#### Formatos solicitados:

- 1500x630px (banner para site desktop)
- 500x300px (banner para site mobile)
- 1200x1200 (post feed)
- 1080x1920px (vídeo de 15 segundos para story)
